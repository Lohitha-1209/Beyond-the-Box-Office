**A Data-Driven Analysis of Movie Performance, Ratings and Profitability**

## About the Project

Beyond the Box Office is a data analytics and machine learning project that explores movie industry trends from 2010 to 2025. It examines the relationship between movie budgets, revenue, ratings, genres, and profitability to understand the factors associated with movie performance.

## Why This Project?

Box office revenue alone cannot explain a movie's overall performance. By analyzing multiple factors, this project aims to uncover meaningful patterns and provide a broader understanding of the movie industry.

## Objectives

- Explore trends in movie ratings, budgets, and revenue.
- Analyze genre-wise movie performance.
- Understand the relationship between budget and profitability.
- Identify patterns across different release years.
- Apply statistical hypothesis testing to investigate movie-related factors.
- Build machine learning models to predict movie revenue.

## Key Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- 15 analytical questions
- 7 statistical hypothesis tests
- Revenue prediction using Random Forest and Gradient Boosting
- Interactive dashboard for visual exploration

## Dataset

**Source:** [TMDB Raw Movie Dataset – Zenodo](https://zenodo.org/records/21920642)

- Time Period: 2010–2025
- Records: Approximately 17,978 movies

## Technologies Used

`Python` `Pandas` `NumPy` `Matplotlib` `Plotly` `Scikit-learn` `Jupyter Notebook`


## Project Outcomes

The project identifies patterns in movie performance, explores relationships between financial and audience-related factors, and evaluates machine learning models for revenue prediction.
